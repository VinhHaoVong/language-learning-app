# Language Learning App

## Project overview

This is a GEAP 103 class project to create an app that helps people learn a language. The project is being developed in collaboration with a partner.
wefhkadhfa

## English vocabulary practice

Word Garden is a browser-based vocabulary app with flashcards, a multiple-choice quiz, and a form for adding your own words. Custom words are saved in your browser on this device.

### Run the app

Open `index.html` in a web browser. No installation or build step is required.
